### accession2taxid.tsv — 4-column NCBI format (MANDATORY)
Source: IndexCreator.cpp line 629, sscanf format: `"%s\t%*s\t%d\t%*d"`
```
accession	accession.version	taxid	gi
ACC_001	ACC_001.1	1001	0
```
- Header line is MANDATORY (parser skips first line unconditionally)
- Column 1: accession (no version) — must match FASTA header prefix before any '.'
- Column 2: accession.version (skipped by %*s — can be same as col 1 with .1 appended)
- Column 3: taxid (integer, must exist in nodes.dmp)
- Column 4: gi (skipped by %*d — use 0)
- TABS between columns, pipe character NOT used in this format

### names.dmp — NCBI taxdump format
```
1	|	root	|		|	scientific name	|
1001	|	Species A	|		|	scientific name	|
```
- Format: `taxid TAB | TAB name_txt TAB | TAB unique_name TAB | TAB name_class TAB |`
- Each field separated by ` | ` (space-pipe-space)
- Line ends with `	|`

### nodes.dmp — NCBI taxdump format
```
1	|	1	|	no rank	|	8	|	0	|	1	|	0	|	0	|	0	|	0	|	0	|	0	|
1001	|	1	|	species	|	0	|	0	|	1	|	11	|	1	|	0	|	1	|	0	|	0	|
```
- Format: `taxid TAB | TAB parent_taxid TAB | TAB rank TAB | TAB ...`
- Minimum required columns: taxid, parent_taxid, rank (remaining pipe-delimited fields can be 0)
- Root node (taxid=1) is its own parent

### merged.dmp — can be empty file
```
(empty — file must exist but zero-byte is valid if no merged nodes)
```

### FASTA format
```
>ACC_001 optional description
ACGTACGTACGT...   (500-1000 bp, valid ACGT nucleotides)
>ACC_002 optional description
ACGTACGT...
```
- Header: `>` followed immediately by accession (no space before accession)
- Accession before any whitespace is what getObservedAccessions() reads
- No version suffix needed in header (the parser strips at '.' anyway)
