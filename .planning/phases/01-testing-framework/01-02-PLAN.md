### Output files to compare (CONTEXT.md locked decision)
- diffIdx — byte-compare with cmp
- info — byte-compare with cmp

### cmp usage — CRITICAL distinction (RESEARCH.md Pitfall 2)
```bash
# WRONG for REGTEST-04 — silent mode never prints byte offset:
cmp -s "$F1" "$F2"  # only sets exit code, prints nothing

# CORRECT — two-step: silent check, then non-silent for offset extraction:
if ! cmp -s "$F1" "$F2"; then
    OFFSET=$(cmp "$F1" "$F2" 2>&1 | awk '{print $5}' | tr -d ',')
    echo "FAIL: $FILE differs at byte offset $OFFSET" >&2
    exit 1
fi

# cmp non-silent output format on mismatch:
# "file1 file2 differ: byte N, line M"
# awk '{print $5}' extracts "N," then tr -d ',' strips the comma
```

### fasta.list must use runtime-computed absolute paths (RESEARCH.md Pitfall anti-pattern)
```bash
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
DATA_DIR="$SCRIPT_DIR/data"
FASTA_LIST=$(mktemp)
trap 'rm -f "$FASTA_LIST"' EXIT   # must append to or precede build dir trap
printf '%s\n' \
    "$DATA_DIR/seq1.fasta" \
    "$DATA_DIR/seq2.fasta" \
    "$DATA_DIR/seq3.fasta" > "$FASTA_LIST"
```

3. Derive paths from script location (NOT hardcoded):
   ```bash

   DATA_DIR="$SCRIPT_DIR/data"
   ```

4. Create temp dirs for two builds + temp fasta.list; set up cleanup trap:
   ```bash
   BUILD1=$(mktemp -d)
   BUILD2=$(mktemp -d)
   FASTA_LIST=$(mktemp)
   trap 'rm -rf "$BUILD1" "$BUILD2"; rm -f "$FASTA_LIST"' EXIT
   ```

5. Generate fasta.list at runtime with absolute paths:
   ```bash
   printf '%s\n' \
       "$DATA_DIR/seq1.fasta" \
       "$DATA_DIR/seq2.fasta" \
       "$DATA_DIR/seq3.fasta" > "$FASTA_LIST"
   ```

6. Build twice using identical arguments (same binary, same data, same flags):
   ```bash
   "$BINARY" build "$BUILD1" "$FASTA_LIST" \
       "$DATA_DIR/accession2taxid.tsv" \
       --taxonomy-path "$DATA_DIR/taxonomy" \
       --threads 1 --max-ram 1

   "$BINARY" build "$BUILD2" "$FASTA_LIST" \
       "$DATA_DIR/accession2taxid.tsv" \
       --taxonomy-path "$DATA_DIR/taxonomy" \
       --threads 1 --max-ram 1
   ```

7. Run validateDatabase on both builds (REGTEST-03):
   ```bash
   if ! "$BINARY" validateDatabase "$BUILD1"; then
       echo "FAIL: validateDatabase failed on build1" >&2
       exit 1
   fi
   if ! "$BINARY" validateDatabase "$BUILD2"; then
       echo "FAIL: validateDatabase failed on build2" >&2
       exit 1
   fi
   ```

8. Byte-compare diffIdx, info, split (REGTEST-02 + REGTEST-04).
   Use two-step cmp: silent check first, then non-silent to extract byte offset:
   ```bash
   for FILE in diffIdx info split; do
       if ! cmp -s "$BUILD1/$FILE" "$BUILD2/$FILE"; then
           OFFSET=$(cmp "$BUILD1/$FILE" "$BUILD2/$FILE" 2>&1 | awk '{print $5}' | tr -d ',')
           echo "FAIL: $FILE differs at byte offset $OFFSET" >&2
           exit 1
       fi
   done
   ```
   DO NOT compare taxID_list or db.parameters.

9. Print PASS and exit 0:
   ```bash
   echo "PASS"
   ```
