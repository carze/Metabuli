<task type="checkpoint:human-action" gate="blocking">
  <name>Run core_nt benchmark on cloud instance (two configurations)</name>
  <what-to-do>
Run the two benchmark configurations on a cloud instance and provide the captured log files (or paste the key timing lines from them).

**Recommended instance:** AWS r7i.32xlarge (128 vCPUs, 1024 GB RAM) or equivalent.
Cost note: ~$8/hr on-demand; ~$2-3/hr Spot. Expected duration: ~10-12 hours for --max-ram 1000, potentially longer for --max-ram 128.

**Steps:**

1. Provision cloud instance with core_nt data staged at `/data/core_nt/`
   - FASTA list file listing all 2,382 .fna paths
   - acc2taxid mapping file
   - NCBI taxonomy directory (names.dmp, nodes.dmp, merged.dmp)

2. Build the binary on the instance:
   ```bash
   cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DCMAKE_C_COMPILER=gcc -DCMAKE_CXX_COMPILER=g++
   cmake --build build --target metabuli -j$(nproc)
   git rev-parse HEAD > build_commit.txt
   ```

3. Run single-flush benchmark (inside tmux):
   ```bash
   tmux new-session -d -s bench1000
   tmux send-keys -t bench1000 \
     './scripts/benchmark_core_nt.sh ./build/metabuli /data/db_1000 /data/fasta.list /data/acc2taxid.tsv /data/taxonomy 1000 100' Enter
   # Monitor: tmux attach -t bench1000
   ```

4. When single-flush completes, run multi-flush benchmark:
   ```bash
   tmux new-session -d -s bench128
   tmux send-keys -t bench128 \
     './scripts/benchmark_core_nt.sh ./build/metabuli /data/db_128 /data/fasta.list /data/acc2taxid.tsv /data/taxonomy 128 100' Enter
   ```

5. After both runs complete, parse the multi-flush log:
   ```bash
   awk -f scripts/parse_bench_log.awk /data/db_128/benchmark_ram128.log
   ```

6. Collect these values and provide them here:
   - From `benchmark_ram1000.log`: FASTA offset pre-pass time, K-mer extraction time, Sort time, Filter time, Write time, "Build complete in X s" total
   - From `awk` output on `benchmark_ram128.log`: min/max/avg for each stage (K-mer extraction, Sort, Filter, Write)
   - Cloud instance type used
   - Git commit SHA (from build_commit.txt)
   - Run date
  </what-to-do>
  <resume-signal>Provide the timing values collected from both runs, or paste key lines from the log files. Type "resume" when ready.</resume-signal>
