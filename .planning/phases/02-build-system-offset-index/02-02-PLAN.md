Implement `void IndexCreator::buildFastaOffsetIndex()` exactly as follows (follow every constraint below):

**Structure:**
1. Print start line: `cout << "Building FASTA offset index..." << endl;`
2. Record start time: `time_t start = time(nullptr);`
3. Set thread count explicitly: inside `#ifdef OPENMP` guard, call `omp_set_num_threads(par.threads);` — mirrors pattern in `createIndex()` (see line 341 of IndexCreator.cpp)
4. Resize outer vector before parallel region: `fastaOffsets.resize(fastaPaths.size());`
5. Parallel loop over files with `#ifdef OPENMP / #pragma omp parallel for schedule(dynamic, 1) / #endif`
6. For each file `i`, each thread:
   a. `fopen(fastaPaths[i].c_str(), "rb")` — binary mode (OFFIDX-03)
   b. If open fails: `continue` (leave `fastaOffsets[i]` empty as sentinel)
   c. Read 2 magic bytes via `fgetc`. If `b0 == 0x1F && b1 == 0x8B`: `fclose(fp); continue;` — gzip sentinel (OFFIDX-05)
   d. `rewind(fp)` — reset position after magic byte check (avoid off-by-one from first 2 bytes)
   e. Local `vector<uint64_t> localOffsets;`
   f. Scan loop using save-then-read pattern (OFFIDX-04 — position recorded BEFORE consuming `>`):
      ```cpp
      while (true) {
          off_t pos = ftello(fp);   // record BEFORE consuming
          int c = fgetc(fp);
          if (c == EOF) break;
          if (c == '>') {
              localOffsets.push_back(static_cast<uint64_t>(pos));
          }
      }
      ```
   g. `fclose(fp);`
   h. `fastaOffsets[i] = std::move(localOffsets);`
7. After parallel loop: compute totals and print summary:
   ```cpp
   size_t totalSeqs = 0;
   for (const auto& v : fastaOffsets) totalSeqs += v.size();
   time_t elapsed = time(nullptr) - start;
   cout << "FASTA offset index built: " << fastaPaths.size() << " files, "
        << totalSeqs << " sequences, " << elapsed << " s" << endl;
   ```
8. Call spot-check validation inline at end of function (see constraints below).

**Spot-check validation (OFFIDX-07) — append at end of buildFastaOffsetIndex():**
- Build `vector<pair<size_t,size_t>> validPairs` from all non-empty `fastaOffsets` entries
- If `validPairs.empty()`: return (all gzip, nothing to check)
- `srand(static_cast<unsigned>(time(nullptr)));` — no fixed seed (per CONTEXT decision)
- `size_t checkCount = std::min((size_t)100, validPairs.size());`
- For each of `checkCount` checks:
  - Pick random index: `size_t idx = static_cast<size_t>(rand()) % validPairs.size();`
  - Destructure: `size_t fi = validPairs[idx].first; size_t ord = validPairs[idx].second;`
  - Open file: `FILE* fp = fopen(fastaPaths[fi].c_str(), "rb");`
  - If open fails: print error to cerr, `exit(EXIT_FAILURE)`
  - Seek: `fseeko(fp, static_cast<off_t>(fastaOffsets[fi][ord]), SEEK_SET)`
  - If seek fails: print error, `fclose(fp)`, `exit(EXIT_FAILURE)`
  - Read char: `int c = fgetc(fp); fclose(fp);`
  - If `c != '>'`: print the failing offset, filename, and actual char to cerr, then `exit(EXIT_FAILURE)`

**Critical invariants to preserve:**
- `fastaOffsets.resize(fastaPaths.size())` MUST happen before `#pragma omp parallel for` to prevent race conditions
- Each thread writes ONLY to `fastaOffsets[i]` where `i` is its own loop variable — no `#pragma omp critical` needed
- `ftello()` called BEFORE `fgetc()` in the scan loop — NOT after (would record position after `>`)
- `rewind(fp)` MUST be called after magic byte check, before scan loop
- Use `off_t` for position type, `fseeko`/`ftello` (not `fseek`/`ftell`) everywhere

**Style:** 4-space indent, opening braces on same line, consistent with existing IndexCreator.cpp style.
